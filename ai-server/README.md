# ai-server

ИИ-ассистент: диалог с моделью (OpenAI-совместимый шлюз), которая действует **от имени пользователя**
через API соседних сервисов. Своей базы нет.

## Запуск

Переменные в корневом `.env`: `AI_TOKEN` (без него чат отвечает `503`), `AI_BASE_URL`
(по умолчанию `https://api.aitunnel.ru/v1/`), `AI_MODEL`.

## API

`POST /ai/api/v1/chat` (нужен вход)

```json
{ "messages": [{ "role": "user", "content": "какие у меня заявки?" }], "approve": ["call_id"] }
```

Ответ — `{ messages, status, pending }`: `messages` — только новые сообщения, их клиент дописывает к своей
истории. `status: "confirm"` — модель хочет изменить данные; `pending` описывает действия. Клиент показывает их
пользователю и повторяет запрос с полной историей и `approve` — id подтверждённых вызовов. Всё, чего нет в
`approve`, считается отказом.

## Как это устроено

- Права = права пользователя: запросы к сервисам идут с его `X-User-Id`/`X-User-Role`.
- Инструменты — `src/ai/tools.ts`. Чтение выполняется сразу, запись (`write: true`) ждёт подтверждения.
- Роль `system` клиент прислать не может; результаты инструментов и текст заявок в промпте названы данными, а не указаниями.
- Лимит — 6 шагов «модель → инструменты» за запрос.
